# FOX CINEMA — مشروع إعادة بناء من الفيديو

## التشغيل الفوري

**المشروع كامل الملفات ولا يحتاج `npm install` أو مكتبات خارجية للتشغيل المحلي.**

على macOS: فك ضغط ZIP ثم افتح `start.command`، أو افتح Terminal داخل مجلد المشروع واكتب:

```bash
node server.js
```

على Windows: افتح `start.bat`، أو من PowerShell:

```powershell
node server.js
```

على Linux: شغّل `./start.sh` أو `node server.js`.

بعدها افتح: **http://localhost:4173/#/home**

**المتطلبات:** Node.js 20 أو أحدث، ومتصفح حديث يدعم WebGL (Chrome / Edge / Safari) لمعاينة السينما 3D. يمكن التحقق من إصدار Node بـ `node --version`.

### تجربة رحلة الحجز كما في الفيديو

1. افتح Movies واختر **Godzilla Minus Zero**.
2. من صفحة الفيلم، اختر تاريخ عرض وفرع ووقت؛ سينقلك إلى خريطة المقاعد.
3. اختر يدويًا المقاعد `C16, D1, D9, D24, G2, G9, G10, M6, M27`، أو استخدم زر **Load video reference seats** أسفل الخريطة.
4. اضغط **View in 3D**؛ يظهر **مجسم WebGL 3D حقيقي** يحتوي على غرفة، شاشة فيلم، سقف، جدران، عوارض، إضاءة، كراسي بنوعين، ممرات، أرضيات مدرجة، درابزين ولوحة MAX.
5. اضغط على شرائح `G2`, `D9`, `G9`, `M27` وغيرها في اللوحة الجانبية؛ تتغير زاوية الكاميرا حسب موضع الكرسي، مع عرض بيانات المقعد كما رُصدت في الفيديو. اسحب داخل المشهد للنظر حولك واستخدم عجلة الفأرة للتقريب.
6. اضغط **Book 9 seats** ثم راجع **Summary → Details → Payment**.
7. أدخل الاسم والبريد ورقم الهاتف وأكمل **demo payment** للحصول على تذكرة تجريبية برمز مرجعي، **من غير دفع مالي حقيقي**.

### السعر المرجعي في الفيديو

- Regular: 180 جنيه للمقعد.
- Premium recliner: 300 جنيه للمقعد.
- مثال 9 مقاعد: 4 Regular + 5 Premium = 2,220 جنيه.
- رسوم الخدمة المرجعية: 15 جنيه لكل مقعد = 135 جنيه.
- VAT المعروض في الفيديو: 14% على (التذاكر + الخدمة) = 329.70 جنيه.
- الإجمالي المعروض: **2,684.70 جنيه**.

**هذه أسعار وضرائب المثال في التسجيل فقط، وليست سياسة مالية إنتاجية أو تقديمًا لخدمة حجز مدفوعة.**

## مهم بشأن «نسخة طبق الأصل 100%»

**النسخة الحالية ليست نسخة 100% من الكود الأصلي المحذوف.** هي تنفيذ جديد مستقل يحاكي هيكل الموقع ومراحل الحجز والـ3D حسب الفيديو المرفوع. لا يمكن استخراج الـGLB / 3D mesh الأصلي، الخطوط الدقيقة، الـAPI الحقيقي، ملفات CSS الأصلية أو جميع عناصر الموقع غير الظاهرة من تسجيل الشاشة وحده. لهذا السبب:

- استخدمنا ألوان وأحجامًا مقدرة من الفيديو مع معايرتها مبدئيًا.
- استخدمنا `DM Sans` و`Instrument Serif` عبر Google Fonts عند توفر اتصال بالإنترنت؛ ليست هناك أدلة تثبت أنها الخطوط الأصلية. بدون إنترنت تستخدم خطوط النظام كبديل.
- اقتُطعت بوسترات وصور مرجعية من فيديو المستخدم، لا من مصدر المشروع القديم. بعض الصور منخفضة الجودة نسبيًا ولا تصلح بديلًا نهائيًا للأصول المرخصة.
- المشهد 3D مصنوع ببرمجة هندسية باستخدام WebGL وليس نموذج GLB المستخرج من الموقع؛ لذلك قد تختلف تفاصيل شكل المقاعد والإضاءة والقياسات.
- المشاهد التي لم تظهر في الفيديو، خصوصًا دفع حقيقي وتذكرة أصلية، لا يمكن الجزم بتطابقها.

### واجهات API

| Route | الطريقة | الوظيفة |
|---|---|---|
| `/api/health` | GET | حالة الخادم |
| `/api/catalog` | GET | الأفلام والسينمات |
| `/api/seats?show=...` | GET | حالات المقاعد للعرض |
| `/api/holds` | POST | إمساك المقاعد لمدة 10 دقائق ومنع التعارض |
| `/api/holds/release` | POST | تحرير المقاعد |
| `/api/bookings` | POST | إنشاء مسودة حجز بالبيانات |
| `/api/pay-demo` | POST | تأكيد تجريبي فقط (دون تحصيل مال) |
| `/api/bookings/:id` | GET | استعادة تذكرة صاحب جلسة الحجز |
| `/api/register` / `/api/login` / `/api/logout` / `/api/me` | متنوع | حسابات محلية تجريبية |

الجلسات محمية بكوكي موقعة HttpOnly، وكلمات مرور حسابات التجربة بـ `scrypt`. قاعدة البيانات المحلية JSON وتجري عملية كتابة معاملات المقاعد بشكل متسلسل داخل عملية واحدة. **ليست قاعدة بيانات إنتاجية متعددة السيرفرات**، ويجب نقلها إلى Postgres أو بديل معاملاتي قبل تشغيل جمهور حقيقي.

## النشر على Vercel

المجلد `public` يمكن نشره كموقع Static (وضع DEMO تلقائي داخل المتصفح). ملف `vercel.json` يجعل هذه العملية أسهل. لكن **خادم Node المتضمن بقاعدة بيانات محلية لا يعمل كحجوزات إنتاجية عند نشر `public` على Vercel**. للتشغيل الفعلي لابد من قاعدة بيانات خارجية، حجز معاملات ذري، مزود دفع مرخّص، اختبار التذاكر/الـQR، إتاحة فروع ومواعيد حقيقية، مراجعة حماية البيانات، وموافقة تسعير وضرائب.

### كيف تطابق المرجع بصورة أدق؟

قارِن لقطات `reference/` مع تشغيل الموقع بنفس أبعاد نافذة التسجيل؛ ثم استبدل الصور والخطوط والـ3D mesh بأصول المصدر الأصلية إذا عُثر عليها. محتوى التسجيل هو مرجع تصميم؛ لا تعتقد أن التطابق البصري ضمان للوظائف الخلفية غير المصورة.

## تحديث V8 — البيانات الحية بدون GitHub Actions

على مشروع Vercel ضع `TMDB_READ_ACCESS_TOKEN` ضمن Environment Variables لبيئة Production فقط.
ملفات API الجديدة في جذر المستودع:

- `GET /api/catalog`: قوائم TMDb للأفلام والمسلسلات، تُخزن في Vercel CDN لمدة 3600 ثانية وتُحدّث عند الطلب بعد انتهاء المهلة.
- `GET /api/title?id=godzilla-minus-zero`: يحاول مطابقة عنوان فيلم تجريبي مع TMDb (العنوان وسنة الإصدار) ويعيد رابط بوستر حقيقي عند توفره. لا يستخدم صورة فيلم مختلف.
- `GET /api/trailer?curated=godzilla-minus-zero` أو `?type=movie&id=123`: يجيب رابط إعلان YouTube صالحًا عند توفره في TMDb.

لو فشل API أو كان المفتاح غير متاح، سيظل الموقع يعرض الكتالوج التجريبي، مع لوحات بديلة تحمل اسم الفيلم للصور غير المنشورة رسميًا. لا يضمن TMDb أن لكل عنوان بوستر أو تريلر رسمي، ولا يعني `Now Playing` وجود تذاكر في قاعات FOX التجريبية.

راجع `V8_CHANGELOG_AR.md` وشروط ترخيص TMDb عند أي استخدام تجاري. لا تُرفع مفاتيح أو Tokens إلى GitHub أو ملفات المتصفح.
