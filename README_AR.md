## عن المشروع

إعادة بناء مستقلة لواجهة سينما من مواد مرجعية قدّمها صاحب المشروع. الكود الأصلي والنموذج ثلاثي الأبعاد الأصلي غير مسترجعين؛ الموديل الموجود تم بناؤه برمجيًا.

يتضمن الموقع صفحات الأفلام ودور العرض وطرق المشاهدة والعروض والمأكولات، بالإضافة إلى صفحات التفاصيل والتريلرات وقسم الممثلين والأدوار، وخريطة المقاعد، ومعاينة مكان المقعد داخل صالة 3D، ثم رحلة دفع **تجريبية فقط**.

## التقنيات المستخدمة

| الجزء | التقنية |
| --- | --- |
| الواجهة | HTML5 + CSS3 + JavaScript ES Modules بدون React أو Next.js |
| الرسوم ثلاثية الأبعاد | **Three.js 0.170.0** + WebGL + مقاعد InstancedMesh + خامات وإضاءة |
| الفيديو | **YouTube IFrame Player API** + HTML5 Video للمصادر المحلية المسموح بها |
| الصوت | YouTube للتحكم في المستوى؛ Web Audio للتوزيع المكاني للفيديو المحلي المصرح باستخدامه |
| البيانات | **TMDb API v3** للأفلام والمسلسلات والبوسترات والممثلين والشخصيات والتريلرات المتاحة |
| الاستضافة | Vercel للملفات الثابتة ووظائف `api/*.js` |
| الخادم المحلي التجريبي | Node.js 20+ مع تخزين JSON محلي |
| الواجهة العربية | اتجاه RTL وخطوط عربية منها IBM Plex Sans Arabic وNoto Naskh Arabic مع خطوط CSS إضافية |
| الاختبارات | Node.js `node:test` |

مكتبة Three.js يتم تحميلها من CDN؛ تحتاج تجربة الـ3D إلى اتصال إنترنت ودعم WebGL في المتصفح.

## أهم الخصائص

- واجهة متجاوبة بالعربية والإنجليزية وكتالوج أفلام عربي وعالمي من TMDb، مع قوائم تجريبية منسقة.
- بوسترات حقيقية عند توافرها وصور احتياطية واضحة عند عدم التوافر، بدون ضمان وجود بوستر لكل عنوان.
- أسماء الممثلين الحقيقية وأسماء الشخصيات وصورهم، وتمييز مؤدي الصوت عند توفر البيانات.
- تشغيل تريلرات من YouTube حسب البيانات المتاحة، مع التحكم في التشغيل والصوت حيث يسمح المتصفح.
- مقاعد A–M واختيار أكثر من مقعد، وخيارات Standard وMAX وIMAX وغيرها حسب بيانات العرض التجريبية.
- انتقال كاميرا 3D بين المقاعد، وإضاءة تتفاعل تقريبياً مع تريلرات YouTube وتستجيب لألوان الفريمات الفعلية للفيديو المحلي المصرح بتحليله.
- واجهة مناسبة للموبايل مع خريطة مقاعد تتسع لعرض الشاشة ودرج تفاصيل قابل للإخفاء.
- ملخص حجز وبيانات العميل ودفع وتذكرة **تجريبيان وغير صالحين للحجز الحقيقي**.

## التشغيل على جهازك

يتطلب Node.js إصدار 20 أو أحدث:

```bash
git clone https://github.com/AhmedKhaledHussein/Fox-cinema-3D.git
cd Fox-cinema-3D
npm start
```

افتح: **http://localhost:4173/#/home**

لتشغيل الاختبارات:

```bash
npm test
```

لا توجد حاليًا حزم npm إنتاجية يجب تنزيلها. الخادم المحلي `server.js` يستخدم بيانات وتذاكر اختبارية داخل `data/fox-db.json` (يُنشأ تلقائيًا ولا يُرفع إلى GitHub)، ولا يصلح كقاعدة بيانات إنتاجية.

## إعداد TMDb على Vercel

في إعدادات مشروع Vercel:

1. اجعل Framework = `Other`، وRoot Directory = `./`، وOutput Directory = `public`، بدون Build Command.
2. أضف متغير البيئة السري `TMDB_READ_ACCESS_TOKEN` في Production.
3. أعد النشر عند إضافة المتغير أو تغييره.
4. اختبر `/api/catalog`؛ لا تضع قيمة الـToken في GitHub أو ملفات `public/`.

الوظائف الحالية:

| المسار | الوظيفة |
| --- | --- |
| `GET /api/catalog` | كتالوج الأفلام والمسلسلات |
| `GET /api/title?id=...` | البحث عن بوستر رسمي مطابق لعنوان تجريبي |
| `GET /api/cast?curated=...` | الممثلون والشخصيات |
| `GET /api/trailer?curated=...` | بيانات التريلر من TMDb |

**التحديث كل 60 دقيقة في Vercel قائم على مدة صلاحية الكاش عند وصول طلب جديد**، وليس مهمة تعمل تلقائيًا في الخلفية بدون زوار. ملف GitHub Actions المجدول اختياري وقد يتعطل عند وجود قيود على الحساب.

## فرق مهم بين التشغيل المحلي والنشر

- **Vercel:** يعرض الموقع ويشغل TMDb Serverless Functions، لكن الحجز التجريبي يتم داخل المتصفح ولا يقفل نفس المقعد بين أجهزة متعددة.
- **`node server.js` محليًا:** يوفر خادمًا تجريبيًا منفصلًا لحسابات اختبار وحجز مؤقت وعمليات دفع شكلية مع تخزين JSON.
- **الوضع التجاري الحقيقي:** يحتاج قاعدة بيانات مشتركة وأمانًا ومخزون جلسات ووسيلة دفع فعلية.

## ملاحظات وحقوق

- يستخدم المشروع بيانات TMDb لكنه ليس معتمدًا أو مدعومًا رسميًا من TMDb.
- YouTube لا يسمح بقراءة ألوان فريمات الـiframe مباشرة؛ إضاءة تريلرات YouTube تقريبية ومتزامنة مع التوقيت وليست تحليلًا فعليًا لكل فريم.
- التصميمات المحلية داخل مجلد البوسترات بدائل فنية، وليست بالضرورة صور الأفلام الرسمية. راجع [سياسة الأصول](./public/assets/ABOUT.md).
- `package.json` يحدد الترخيص الحالي: `UNLICENSED`. لا يعني نشر المستودع السماح بالاستخدام التجاري لحقوق الغير.
- لا تتضمن النسخة الحالية النموذج أو المصدر الأصلي للموقع المرجعي المفقود.
